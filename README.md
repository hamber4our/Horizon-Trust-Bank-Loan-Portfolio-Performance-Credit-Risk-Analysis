# Horizon-Trust-Bank-Loan-Portfolio-Performance-Credit-Risk-Analysis
An interactive Power BI dashboard project focused on analysing loan portfolio performance, repayment behaviour, profitability, and credit risk for Horizon Trust Bank.    Using Power BI, DAX, and data modelling, I transformed 5,000 loan records into an interactive two-page dashboard covering both profit and loss analysis.
## Key Highlights

- $636.68M in total loans issued.
- $383.08M in total amount paid.
- 60.17% loan collection rate.
- $253.60M in outstanding unpaid loans.
- 4.18% default rate across 209 defaulted loans.
- $53.87M in high-risk loan exposure.

## Key Insights

- Mortgage loans account for the largest share of the loan portfolio, highlighting significant exposure within this category.
- Loans overdue by 91–120 days represent the highest unpaid exposure, at $69.80M.
- Default rates vary across branches, revealing areas that warrant further investigation.
- Mass Market customers account for the majority of defaulted loans in the dataset.
